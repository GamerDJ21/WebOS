VoxelOS is my first web-based operating system, designed with a clean, modern desktop interface and essential built-in applications. It currently features a Notes app for writing, a Calculator for quick calculations, and a Browser for web access. The OS also includes a functional taskbar, app icons, desktop environment and a system clock.

Note: The browser will work by clicking the arrow button in the right corner.
AI was used for debugging and cleaning the code. Some pieces of code are written by AI because I couldn't figure them out :p .
